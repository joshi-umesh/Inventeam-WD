# Inventeam-WD

Public website-development workspace for projects explicitly designated **Inventeam**.

## Project routing rule

At the start of each website project, the project owner will identify it as either **Inventeam** or **UJ**:

- **Inventeam project:** store the project code, client assets, documentation, and project-specific implementation in this repository: [Inventeam-WD](https://github.com/joshi-umesh/Inventeam-WD).
- **UJ project:** follow the private UJWD master repository and its architecture/governance rules: [ujwd-site-builder-ChatGPT](https://github.com/joshi-umesh/ujwd-site-builder-ChatGPT).
- Never mix client-specific material across project types without explicit direction.
- For all website POCs, prepare a temporary live preview and provide verified preview links. Keep preview deployments distinct from final production launch.
- Do not commit credentials, API keys, passwords, or other secrets. Do not make unverified business claims. Require owner approval before a final production launch.

## Inventeam client projects

Each project should have its own directory under `clients/<client-name>/`, including a README with status, scope, requirements, assets/provenance, preview URLs, QA notes, and pending owner decisions.

### Royal Industries

Royal Industries is an Inventeam project. Its existing POC was created in the private UJWD repository branch `poc/royal-industries-options`; it is being migrated here so Inventeam-owned client work remains in the Inventeam repository. Keep it clearly marked as a draft/POC until approved.
